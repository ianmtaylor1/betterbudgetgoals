# betterbudgetgoals
Demo of better budget automations for gradual savings goals in Actualbuddget.

This repo contains:
1. Documentation of the proposed algorithm published and available at <https://ianmtaylor1.github.io/betterbudgetgoals/>.
2. A Python package supporting the documentation.

The documentation is the main description of the proposed algorithm, laying out its background and goals, and describing how it works. The Python package is a proof of concept meant to remove any ambiguity, and be used in code snippets in the documentation. Obviously, the algorithm would need to be re-written in Javascript/Typescript within the Acutalbudget codebase to be used. I'm a statistician, not an application developer, so Python is the closest thing I know to a *lingua franca*.
